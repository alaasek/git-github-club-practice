# Git & GitHub Glossary | Glossaire Git & GitHub

Short definitions for workshop learners.
Définitions courtes pour les participants à l'atelier.

| Term | English | Français |
|---|---|---|
| Git | A version control system that tracks changes to files. | Un système de gestion de versions qui suit les modifications des fichiers. |
| GitHub | An online platform for hosting Git repositories and collaborating. | Une plateforme en ligne pour héberger des dépôts Git et collaborer. |
| Repository (repo) | A project folder tracked by Git, including its history. | Un dossier de projet suivi par Git, avec son historique. |
| Commit | A recorded snapshot of selected changes. | Un instantané enregistré des modifications sélectionnées. |
| Working tree | The files and folders you are currently editing. | Les fichiers et dossiers que vous êtes en train de modifier. |
| Staging area | The place where you prepare changes for the next commit. | La zone où vous préparez les modifications du prochain commit. |
| Branch | An independent line of development. | Une ligne de développement indépendante. |
| Merge | Combining changes from different branches. | La combinaison des modifications de plusieurs branches. |
| Remote | A named reference to a repository hosted elsewhere. | Une référence nommée vers un dépôt hébergé ailleurs. |
| Clone | A local copy of a remote repository and its history. | Une copie locale d'un dépôt distant et de son historique. |
| Fork | Your GitHub-side copy of someone else's repository. | Votre propre copie GitHub du dépôt d'une autre personne. |
| Push | Sending local commits to a remote repository. | Envoyer des commits locaux vers un dépôt distant. |
| Fetch | Downloading remote updates without integrating them. | Télécharger les mises à jour distantes sans les intégrer. |
| Pull | Fetching and integrating remote changes. | Récupérer et intégrer les changements distants. |
| Pull Request (PR) | A proposal to review and merge changes into another branch or repository. | Une proposition pour examiner et intégrer des modifications dans une autre branche ou un autre dépôt. |
| Merge conflict | A situation where Git needs help deciding how overlapping changes should be combined. | Une situation où Git a besoin d'aide pour combiner des modifications qui se chevauchent. |
| `.gitignore` | A file listing untracked files Git should normally ignore. | Un fichier qui liste les fichiers non suivis que Git doit généralement ignorer. |

## Remember | À retenir

**EN:** Git manages versions; GitHub makes collaboration around Git repositories easier.  
**FR :** Git gère les versions ; GitHub facilite la collaboration autour des dépôts Git.
