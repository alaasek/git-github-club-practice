# Contributing

Thank you for practising Git and GitHub with us!

## Before opening a Pull Request

1. Create a branch; do not work directly on `main`.
2. Make a small change related to an Issue or the workshop challenge.
3. Run `git status` and inspect `git diff`.
4. Commit with a clear message, for example:
   - `docs: add my name to contributors`
   - `docs: fix installation typo`
   - `docs: add Git glossary term`
5. Push your branch and open a Pull Request.

## Pull Request description

Please include:
- **What changed?**
- **Why did you make this change?**
- **How can the reviewer verify it?**

## Review etiquette

Be constructive, specific, and kind. Ask questions when something is unclear. A review is about improving the contribution, not judging the contributor.
